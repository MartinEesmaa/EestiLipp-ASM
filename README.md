# EestiLipp-ASM

Eesti lipp DOS-i programm on kirjutatud x86 Assembler programmikeel.

Ekraanpilt:

![ESTLIPP](ESTLIPP.png)

## Funktsioonid

- Kasutab NASM 16-baiti x86 programmi
- Joonistab kolm värvid Eesti lippu (sinine-must-valge)
- Ainult 50 baiti faili suurus vähendamine
